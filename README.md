# Иван Архипов · резюме

Статический сайт с главной страницей, галереей документов и контактами.

## Добавить грамоту или сертификат

Создай папку внутри `content/documents/`, например `content/documents/kurs-po-dizajnu/`. Положи в неё `description.md` и фотографии страниц. Поддерживаются JPG, PNG, WebP и AVIF. Назови их `01.jpg`, `02.jpg` и так далее. Сайт сортирует страницы по номерам.

```markdown
# Название документа

Тип: Сертификат
Организация: Название организации
Год: 2026

Пара предложений о курсе, событии или достижении.
```

Поля «Тип», «Организация» и «Год» можно опустить. Одна папка соответствует одному документу. Галерея скрывает демонстрационные карточки, когда появляется первый документ без поля `Образец: да`.

## Обновить опыт и контакты

В `content/experience.md` добавь имя организации под заголовком второго уровня и напиши должность. Ссылка и логотип необязательны. Файлы логотипов хранятся в `content/logos/`.

```markdown
## Организация

Должность или краткое описание работы

![Организация](logos/organization.svg)
[Сайт](https://example.org)
```

Имя, текст главного экрана, роли, навыки, проекты и контакты редактируются в `content/profile.json`. Портрет хранится в `src/assets/portrait.webp`. Он обработан на основе фотографии со страницы сотрудника «Школы 800». [Источник фото](https://shkola800.ru/about/komanda/administrativno-texnicheskij-personal/ivan-alekseevich-arxipov/)

## Развернуть на GitHub Pages

Загрузи исходники в ветку `main` и выбери **Settings → Pages → Source → GitHub Actions**. После включения источника запусти **GitHub Pages** на вкладке **Actions**, если первый запуск уже завершился. Дальше изменения в `main` автоматически пересобирают и публикуют сайт.

Для локальной сборки нужен Python 3.10 или новее.

```sh
python3 scripts/build.py
python3 -m http.server 8000 --directory dist
```

Сайт откроется по адресу `http://localhost:8000/`.
